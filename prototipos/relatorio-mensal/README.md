# Relatório mensal — modelo oficial (M5.7), protótipo navegável

`relatorio.html` mostra, com **dados fictícios** (proprietária, imóvel, hóspedes, códigos e valores
inventados), a estrutura do relatório mensal oficial decidida por Diego em 4/10/2026 a partir do
modelo que a Lia (Codex) montou com ele para setembro/2026. Abra no navegador; "Imprimir" mostra as
quatro páginas em A4.

- Especificação: `requisitos/product/RELATORIO-MENSAL.md`.
- Cores e fontes: os tokens do M7.5 (`requisitos/product/DESIGN.md`), copiados aqui como variáveis CSS.
- Não é o produto: a implementação (PDF gerado pelo sistema, portal, e-mail) é o item M5.7 do ROADMAP.
