# Referências Visuais — Histórico e Laboratório

Objetivo: preservar visuais antigos, screenshots, layouts e referências para comparação calma com o SCL 2.0 atual.

## Regra central

**Referência não é decisão.**

Uma tela antiga pode conter uma solução melhor, mas ninguém deve restaurá-la automaticamente só porque parece boa isoladamente.

## Quando Diego enviar uma referência

Registrar:
- origem aproximada;
- data/período, se conhecido;
- qual tela/fluxo representa;
- o que parece melhor nela;
- o que parece pior;
- qual problema atual ela talvez resolva;
- opinião de Rivers, Lia e Sage quando relevante;
- decisão: manter atual / testar / adaptar / arquivar.

## Critérios de comparação

Priorizar:
1. clareza para hóspede;
2. confiança;
3. conversão;
4. facilidade operacional;
5. consistência do sistema;
6. estética;
7. custo de implementação.

Estética sozinha não vence fluxo melhor.

## Processo

1. Diego envia screenshot/referência.
2. Rivers organiza e contextualiza.
3. Lia pode avaliar uso/navegação.
4. Sage pode avaliar impacto técnico.
5. Se houver consenso ou hipótese forte, criar teste pequeno.
6. Só implementar depois de decisão explícita ou evidência suficiente.

## Organização sugerida

Quando houver arquivos de imagem, usar futuramente:
`references/visual/`

E manter um índice textual aqui para que o contexto sobreviva mesmo se uma imagem mudar de lugar.
